# 开心学单词 · WordsFunny

一个免费、原创、面向孩子的趣味英语单词学习平台。纯静态 HTML / CSS / JavaScript，无需后端，部署到 GitHub Pages 即可直接在线游玩，手机、平板、电脑都适配。

在线体验：<https://changxueyi.github.io/words-funny/>

## 特色

- **6 本主题单词书**：动物、食物、颜色、数字、家人身体、自然天气，共 72 个常用单词，每个词都有图片、音标、中文、英文例句。
- **真人发音**：使用浏览器内置的 Web Speech API 朗读英文单词与例句（无需联网下载），右上角可一键开关发音。
- **五种玩法，边玩边记**：
  1. 🃏 学习卡：看图听音、点击翻面看中文和例句。
  2. 👂 听音选词：听发音，选出对应的图片和中文。
  3. 🖼️ 看图选词：看图片，选出正确的英文单词。
  4. 🔤 拼单词：把打乱的字母重新排成单词。
  5. 🧠 记忆配对：翻牌把英文和中文配成一对。
- **星星激励 + 学习进度**：答对收集星星，掌握进度保存在本地浏览器，鼓励孩子持续学习。
- **移动端优先**：大按钮、大字体、单手可玩。

## 本地运行

纯静态页面，任意静态服务器即可：

```bash
python3 -m http.server 8000
```

然后打开 `http://localhost:8000`。
